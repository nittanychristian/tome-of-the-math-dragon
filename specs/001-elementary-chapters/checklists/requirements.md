# Requirements quality checklist

- [x] Five grades and independently selectable chapters defined.
- [x] Existing-code compatibility has explicit acceptance scenarios.
- [x] Curriculum baseline and instructional limits stated.
- [x] Topic-to-generator coverage required.
- [x] Story continuity and child-appropriate language specified.
- [x] Progression, help, replay and boundary cases included.
- [x] Validation criteria are measurable.
- [x] Grade 5 prerequisites cross-checked against every Course 1 chapter and opening topic.
- [x] Continuous practice and a dedicated single-digit facts quest specified and tested.
- [x] Illustrated questions use typed data sampled alongside their answers, not text parsing.
- [x] Visuals show units, equal scales, keys, readable labels and accessible descriptions.
- [x] The same diagram persists in help and the failed-problem walkthrough.
- [x] All seven visual families checked against answers and exercised in a real browser at phone widths.
