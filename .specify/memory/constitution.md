# Tome of the Math Dragon Constitution

1. Preserve existing middle school curriculum, stable identifiers and passcodes. Display order must not redefine saved progress.
2. Each playable topic needs a mathematically correct problem generator, reachable quest, explanatory hints and age-appropriate wording. Document curriculum coverage.
3. Elementary stories must form a coherent prequel to the existing adventure without requiring elementary completion to resume middle school.
4. Keep the existing Elm application architecture and dependency footprint where practical. Use the Nix development environment for builds and checks.
5. Specify, plan and task new features before implementation. Verify generator boundaries, progression and legacy compatibility, then compile and format affected Elm files.

Changes to these principles must describe their compatibility impact. Current user instructions take precedence.

Version: 1.0.0. Ratified: 2026-10-23.
